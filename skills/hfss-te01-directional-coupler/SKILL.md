# HFSS TE01 双孔定向耦合器

帮助用户得到几何可核对、模式可识别、求解可验证的圆波导 TE01 定向耦合器。先检查现有模型和保存的解，再针对证据修改几何或求解设置。

## 资源

- 复刻本项目或比较参数时读 [references/verified-case.md](references/verified-case.md)。包含唯一保留的最佳版、论文与本模型的实际差异、端口位置和五个验证频点。
- 操作 HFSS、修复孔距或检查弱信号时读 [references/hfss-workflow.md](references/hfss-workflow.md)。包含 PyAEDT 的缓存、面编号、模态与收敛注意事项。
- 用 [scripts/export_hfss.py](scripts/export_hfss.py) 从明确选定的现有 AEDT 进程导出保存的 S 参数；不启动求解、不改激励、不创建工程。
- 用 [scripts/coupler_metrics.py](scripts/coupler_metrics.py) 审核 CSV 和计算方向性；只依赖 Python 标准库。
- [assets/te01-24ghz-best.aedtz](assets/te01-24ghz-best.aedtz) 是仅含最佳设计的 HFSS 模型归档，无网格/场结果。恢复到用户工作目录后重新求解；不要在安装的 skill 目录中运行求解。

## 判断顺序

1. 列出正在运行的 AEDT 会话，选定用户操作的进程和已有工程、设计。检查是否正在求解。把机器路径、进程号、模式编号当作当前环境信息，不能沿用旧会话的值。
2. 从论文图、表和模型历史建立物理坐标映射。记录主、副波导传播轴，矩形截面宽边方向，两个孔的**全局中心坐标**及两个方向的**完整中心距**。记录实际局部壁厚；柱体钻孔深度不等于金属壁厚。
3. 波导 TE01/TE10 S 参数分析采用 Driven Modal 和 Wave Port。圆波导需要包含目标 TE01 及相关传播模式；模态数量由截面和频率决定。确认 TE01 的环向电场分布，不能只用默认 Mode 1，也不能把本案例的 Mode 6 当作所有工程的固定编号。
4. 检查孔是否贯通两个波导、是否接到矩形宽壁；几何再生后按空间位置和面积重新匹配端口面，PEC 覆盖其余外壁。随后验证设计。
5. 读取明确的当前几何、自适应解和频点。比较同一 TE01 入射下的两个副端口。定义正耦合损耗 C=-20log10|S耦合|，正隔离度 I=-20log10|S隔离|，方向性 D=I-C。曲线的负 dB 值之差也是 D，但隔离度本身不是两路差值。
6. 方向性低时，先核对宽壁、孔距和两个传播方向的相位路径。用少量可比较的几何试算和复数 S 参数指导修改。需要求解时聚焦小孔网格、目标模态及弱输出项的稳定性；全矩阵绝对 Delta S 很小仍可能不足以证明隔离端准确。
7. 保存最终模型和验证证据。用户明确要求只留最佳版时，核对目标设计的结果，再删除其他设计、旧求解设置和旧参数变体，删除后复查最终结果不变。普通调试任务不自动授权清理其他工程或发布到 GitHub。

## 本案例的关键限制

最佳简化模型在 24 GHz 的耦合信号约 -62.35 dB、隔离信号约 -109.80 dB、方向性约 47.45 dB。它的实际孔中心距为 X=4.90 mm、Z=5.04 mm，**与论文表中 2.45/2.44 mm 的孔距标注不同**；论文没有提供足够信息证明这些标注是半偏移量。不要把优化成功解释为作者采用了加倍孔距。

本模型未加入论文的标准波导、过渡段和其他连接细节。五个频点支持这些离散位置的性能比较，不能当作已细扫确认的连续带宽或完整器件复刻。随网格、端口基和制造误差变化，隔离谷底可能移动；引用数值时附带几何与验证范围。
