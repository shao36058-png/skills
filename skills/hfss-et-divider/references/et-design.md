# E 面 T 形双膜片功分器：几何与结果解释

本文记录一个可复用的建模约定和已求解示例。尺寸用于说明参数及坐标关系，不是其他频段、波导截面或加工条件下的通用最优值，也不是额定功率或加工验收指标。复用前应读取当前工程的实际几何、坐标系、端口和求解设置。

## 几何及坐标约定

本例为空气填充矩形波导 E 面 T 形结，采用全局直角坐标：

- `a` 为 x 方向宽边尺寸，所有支路的 x 范围均为 `[-a/2, a/2]`。
- `b` 为窄边尺寸。直通横臂的 y 范围为 `[-b/2, b/2]`，沿 z 延伸；横臂总长 `c` 对应 z 范围 `[-c/2, c/2]`。
- 输入支路沿 +y，从 T 结外壁 `y=b/2` 延伸到 `y=b/2+d`，截面为 x 方向宽 `a`、z 方向高 `b`。其与横臂在结区连通；若用两个空气体建模，应确保并集连通且没有内部金属封面。
- 端口 2 位于输入支路末端 `y=b/2+d`；端口 1、3 分别位于横臂 `z=-c/2`、`z=+c/2`。
- T 形空气腔整体 y 向跨度为 `d+b`。这里 `d` 是从 T 结外壁到输入端口的支路长度，不是整体高度。

若原工程使用相对坐标系，先检查新几何的参考坐标系及实际全局位置。特别是原点已经位于 `y=b/2` 时，再在局部 y 坐标中加一次 `b/2` 会让膜片位置重复偏移。参数表达式、创建操作的参考坐标系和实际面中心应相互一致。

## 对称感性膜片

两片膜片都位于输入支路内，法向沿 y。每片从 x 方向的左右侧壁对称伸入，z 方向贯穿整个窄边 `b`，中央保留宽 `w_i`、高 `b` 的矩形开口。

对第 i 片定义：

| 量 | 定义或公式 |
|---|---|
| `w_i` | 中央开口在 x 方向的全宽 |
| `t_i` | 膜片沿 y 方向的厚度 |
| `d_i` | 从 T 结外壁 `y=b/2` 到膜片中心的距离 |
| 两侧各自伸入深度 `p_i` | `(a-w_i)/2`，不是两侧深度之和 |
| 全局中心 y | `b/2+d_i` |
| 近面/远面距 T 结外壁 | `d_i-t_i/2` / `d_i+t_i/2` |
| 开口 x 范围 | `[-w_i/2, w_i/2]` |
| 左侧金属占据的 x 范围 | `[-a/2, -w_i/2]` |
| 右侧金属占据的 x 范围 | `[w_i/2, a/2]` |
| 膜片的 z 范围 | `[-b/2, b/2]` |

在采用默认 Perfect E 外边界的空气腔模型中，可从空气体扣除上述左右金属占据区域，使新增腔壁成为理想导体表面。采用实体金属模型时，应保持相同电磁几何，并另外核实材料、边界和求解区域。

保持关于 x=0 及 z=0 的几何对称性，避免通过移动单侧膜片或改变单个输出支路来改善输入匹配。本例的感性膜片缩窄的是宽边 x；缩窄窄边 z 的对称膜片属于不同的容性匹配结构，不能仅交换参数名称套用。

## 示例尺寸及派生距离

以下均为 mm，`t_1=t_2=0.250`。

| 参数 | 数值 |
|---|---:|
| 波导宽边 `a` | 10.668 |
| 波导窄边 `b` | 4.318 |
| 横臂总长 `c` | 60.000 |
| 输入支路长 `d` | 30.000 |
| 第一片开口 `w_1` | 4.950 |
| 第二片开口 `w_2` | 6.560 |
| 第一片中心距离 `d_1` | 2.277 |
| 第二片中心距离 `d_2` | 7.828 |

| 派生量 | 第一片 | 第二片 |
|---|---:|---:|
| 左右两侧各自伸入深度 `(a-w_i)/2` | 2.859 | 2.054 |
| 近面距 T 结外壁 | 2.152 | 7.703 |
| 远面距 T 结外壁 | 2.402 | 7.953 |
| 全局中心 y | 4.436 | 9.987 |
| 全局近面 y | 4.311 | 9.862 |
| 全局远面 y | 4.561 | 10.112 |

其他距离：

- 两片中心间距：`d_2-d_1=5.551 mm`。
- 两片相邻表面净距：`d_2-d_1-(t_1+t_2)/2=5.301 mm`。
- 第二片远面至输入端口：`d-d_2-t_2/2=22.047 mm`。
- 输入端口全局 y：`b/2+d=32.159 mm`。
- 空气腔整体 y 向跨度：`d+b=34.318 mm`。
- 横臂端口位于 `z=±30.000 mm`；开口半宽分别为 `2.475 mm` 和 `3.280 mm`。

延长结区以外的均匀波导，主要改变端口参考面传播相位；匹配膜片到 T 结的距离不应随支路总长等比例放大。改变 `a`、`b`、材料或结区形状则可能改变匹配，应重新求解。

## 端口、等分及反射

用端口 2 的第 1 模馈入时，输入反射为 `S(2:1,2:1)`，两路传输为 `S(1:1,2:1)` 和 `S(3:1,2:1)`。读取现有工程时先核实端口的物理面及模式，不能根据端口编号猜测馈入口。

E 面 T 形结的两输出为反相等分。只有在两个输出端口的模式极性/积分线采用一致约定后，180° 相位差才可直接比较；本例两输出积分线沿全局 +y，输入端口第 1 模积分线沿全局 +z。改变模式参考极性可使显示相位改变 180°，不代表器件突然改变物理工作方式。

采用功率归一化 S 参数时：

```text
输入反射功率比 = |S22|²
输出基模功率比 = |S12|² + |S32|²
理想无耗二等分每路传输 = 10 log10(1/2) = -3.0103 dB
```

每路约 -3 dB 本身表示功率分到两路，不表示一半输入功率被耗散。对于单模、无辐射、无耗壁的匹配模型，应检查 `|S22|²+|S12|²+|S32|²`；若还存在其他传播模或辐射通道，应将相应功率纳入。不能把所有未进入某一输出端口的功率都称为导体损耗。

互易无耗三端口无法三端同时匹配。针对端口 2 匹配后，两个输出口仍有反射及相互耦合；单独看输出口的回波或隔离度，不能替代端口 2 输入时的功分性能评价。

## 反向用作合成器

反向合成要求两路在所选参考面上相干。端口 1、3 应使用与目标合成模式对应的幅度和相位，不能分别输入任意独立信号后直接声称功率会全部进入端口 2。

在相同模式参考约定下，端口 2 的出射波为：

```text
b2 = S21*a1 + S23*a3
```

因此两个合成贡献 `S21*a1` 和 `S23*a3` 需要同相。本例等幅 E-T 在匹配频段内 `S21≈-S23`，对应端口 1、3 等幅、约 180° 相差的输入。连接电缆或附加波导的传播相位必须折算到这两个参考面；实际幅差、相位差及端口负载失配都会影响合成效率和返回源端的功率。

## 本例结果的证据边界

最终示例在 23–25 GHz 的插值扫频输出中导出 21 个频率样点，间隔 0.1 GHz，样点中最差输入 `S22≈-28.3418 dB`。**这是插值扫频的 21 点输出，不是 21 个独立离散频点求解。** 不能将其描述成“21 点均独立求解/收敛”，也不能由这些样点单独证明任意频率处的连续全带下界。复用时应按当前任务所需精度区分自适应网格收敛、插值精度和离散频点验证。

本例最终端口采用 8 模；此记录本身不证明模式截断误差已收敛，也不是所有 E-T 工程都必须使用的固定值。应根据最高工作频率、实际传播模数、端口与不连续处距离，以及未计入消逝模的衰减长度选择模式数。对称膜片仍可耦合与主模对称性相容的 TE30 等高阶模；“低于截止”不等于其近场在端口已经可以忽略。

当端口很靠近膜片时，可比较更多端口模或延长均匀直段后的结果。比较延长直段前后的复数 S 参数时，要先处理参考面传播相位；只比较幅度时也要保持其他求解设置一致。无耗模型的功率和接近 1 只是一项一致性检查，不能替代网格及模式截断收敛检查。

## 材料、加工与功率能力

本示例以空气腔和理想导体壁量化匹配改善，没有据此计算真实金属的有限电导率、表面粗糙度、接触缝隙、圆角或热效应。理想 PEC 中没有真实导体发热，不能从低反射、接近 -3 dB 的传输、或某个任意归一化激励场值直接额定连续波（CW）功率。

若任务要求加工尺寸或 CW 功率能力，应另行明确材料及表面、实际圆角和最小间隙、工作介质/压力、负载失配、散热条件和允许温升，再评估峰值电场、击穿及导体/接触损耗。理想尖角处的数值峰值电场也不能直接作为真实加工件的可靠功率额定依据。
